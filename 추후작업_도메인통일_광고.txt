대량발송 엑셀 변환기 — 추후 작업: 도메인 통일 & 광고
작성일: 2026-10-29
상태: 보류 (프로그램 안정화 후 진행)

====================================================================
진행 순서
====================================================================

1단계. 프로그램 안정화 (현재 단계)
  - 실제 엑셀 파일로 네이버 × 로젠, 쿠팡 × 로젠 변환이 끝까지 되는지 확인
  - 문제 없으면 2단계로

2단계. 주소를 홈페이지 도메인으로 통일
  - 목표 주소: https://codivostudio.com/tools/excel-converter/
  - 현재: 홈페이지 버튼이 https://excel-merge-five.vercel.app/tools/excel-converter 로
          직접 연결됨. codivostudio.com/tools/excel-converter 는 404
  - 할 일:
    (1) 홈페이지(Vercel) 프로젝트 설정에 rewrite 추가
        - next.config.js 의 rewrites 또는 vercel.json 의 rewrites에:
          source:      /tools/excel-converter/:path*
          destination: https://excel-merge-five.vercel.app/tools/excel-converter/:path*
        - 변환기가 이제 경로를 스스로 처리하므로 예전처럼 앞부분을 떼는
          프록시 코드([...path].ts)는 필요 없음
        - 외부 주소(https://...)로 보내는 rewrite라서 홈페이지에 basePath가 있어도 됨
    (2) /tools/bulk-shipping-excel-converter 페이지의 "서비스 이용하기" 버튼 링크를
        https://codivostudio.com/tools/excel-converter/ 로 변경
    (3) 확인
        - https://codivostudio.com/tools/excel-converter/ 에서 화면이 뜨는지
        - 파일 2개를 올려서 변환·다운로드가 되는지
        - 블로그 글에 있는 옛 링크(/tools/excel-converter/)도 함께 살아나는지
  - 필요한 것: 리뉴얼한 홈페이지 저장소 위치

3단계. 광고 (사용자가 생긴 뒤)
  - 광고 신청(예: 구글 애드센스) → 승인 → 변환기 화면에 광고 영역 추가
  - 광고는 보통 내 도메인(codivostudio.com) 기준으로 승인받으므로 2단계가 먼저 필요
  - 광고를 넣은 뒤에는 화면 속도, 레이아웃 깨짐, 버튼이 가려지는지 확인

====================================================================
왜 이 순서인가
====================================================================

  - 프로그램이 잘 동작해야 사용자가 남고, 사용자가 있어야 광고 수익이 남
  - 광고는 화면을 느리게 하거나 깨뜨릴 수 있어서, 기능이 안정된 뒤에 넣어야
    문제 원인을 구분하기 쉬움
  - 주소는 나중에 바꾸면 즐겨찾기·공유 링크·검색 노출이 흩어지므로,
    광고와 별개로 너무 늦지 않게 통일해 두는 것이 좋음

====================================================================
배경 (2026-10-29 오류와의 관계)
====================================================================

  - 원래는 예전 홈페이지의 프록시가 codivostudio.com/tools/excel-converter/ 요청을
    Vercel 변환기로 넘겨주는 구조였음 (광고를 홈페이지 도메인에서 돌리려던 목적으로 기억)
  - 홈페이지를 리뉴얼해 Vercel로 옮기면서 프록시가 빠졌고, 버튼이 vercel.app로
    직접 연결되면서 변환 요청이 404 → "네트워크 오류"가 났음
  - 변환기 쪽(vercel.json rewrite + Flask 라우트)을 고쳐서 지금은 프록시 없이도 동작함
  - 자세한 내용은 같은 폴더의 작업요약.md 참고
